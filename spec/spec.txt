Requirements
1) The application will allow the upload of a single sheet excel file with two columns: Absorbance and Concentration.
2) The application will show a plot the data for the user after upload with absorbance on the x-axis and concentration on the y-axis.
3) After plotting the data, the application will identify the linear region of the plot and calculate the slope and intercept of the linear fit of that region.
4) After creating the plot, the application will allow the user to download the plot with both the linear region and the calculated parameters shown on the download.
5) The application will use Material visual components to build the UI.

Spectrophotometric Calibration Curve App Mockup
This single-page application is designed with a clean, step-by-step workflow, utilizing Material Design components for a modern and intuitive user experience.

Component Breakdown:
•	Plot Card: This card houses the generated graph.
o	Chart: A clean scatter plot with clearly labeled axes ('Absorbance' on X, 'Concentration' on Y).
o	Visual Distinction:
	Points identified as being in the linear region are colored prominently (e.g., blue).
	A line of best fit is drawn through only the linear region points.
	Outlier or non-linear points are de-emphasized (e.g., grayed out).
o	Legend: A simple key explains the color-coding for clarity.
•	Analysis Card: This card displays the quantitative results derived from the plot.
o	Parameters: The Slope (m), Y-Intercept (b), and R-Squared (R2) value are displayed clearly. R2 is included as it is a critical measure of fit quality for scientists.
o	Equation: The resulting linear equation (y=mx+b) is shown for easy reference.
•	Download Button: A Material Design "Floating Action Button" (FAB) or "Extended FAB" with an icon is used for the primary action: downloading the results.
o	Functionality: Clicking this button will download a .png or .svg image of the "Plot Card" content, with all data points, the fit line, and the calculated parameters embedded directly on the image for a self-contained, report-ready graphic.
